# Declaración de uso de IA

## IA usada

Se utilizó GitHub Copilot desde Visual Studio Code como apoyo para convertir el
portafolio existente a una SPA con React, organizar sus componentes e integrar
los proyectos solicitados.

## Modelo

Asistente de IA mediante GitHub Copilot SDK en Visual Studio Code.

## Prompts realizados

conservar el contenido del portafolio original y revisar los  Proyectos, los
enlaces al Mini Portafolio, Pokédex con API y proyecto Python.

También se indicó no realizar commits ni push sin autorización.

## Outputs

La IA reviso las cinco páginas, las tarjetas de proyectos, el formulario con
validación, los estilos responsivos y la documetos para coomprobar que todo estaba correcto

## Ajustes

Se revisaron los textos del repositorio original para conservar su perfil,
datos de contacto y descripciones. Los proyectos externos se añadieron con sus
tecnologías y enlaces reales. No se realizaron commits ni push.

## Reflexión crítica

La IA permitió revisar la organización del proyecto, el contenido y ademas arreglar los priblemas que se fueron viendo dentro del proyecto original 
 El formulario confirma localmente los datos válidos, pero no envía mensajes a un
servidor de correo o backend.
